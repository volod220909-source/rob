Приватна кімната за кодом
Для роботи потрібен інтернет і налаштований Firebase.
Кімната
Повідомлення бачать учасники, які знають код кімнати. Не надсилай паролі чи приватні дані.

Шифрування

Результат:
Перший запуск — потрібне одноразове налаштування.
Цей HTML-файл є інтерфейсом чату, але не містить власного сервера. Щоб Android та iPhone могли обмінюватися повідомленнями через інтернет, використовується проєкт Firebase: увімкни Authentication → Anonymous та створи Cloud Firestore. У Firestore Rules встанови правило: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rooms/{roomId}/messages/{messageId} {
      allow read, create: if request.auth != null;
    }
  }
}
Це базове демо-правило: будь-який авторизований анонімний користувач, який знає ID кімнати, може читати й надсилати повідомлення. Для публічного використання потрібні сильніші правила, обмеження доступу та захист від спаму.
